# Portafolio de Emily Cárdenas

Portafolio web de Animación 3D con proyectos de modelado, composición de escenarios, texturizado, iluminación y renderizado.

## Publicación en GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube **todo el contenido de esta carpeta** al nivel principal del repositorio: `index.html`, `assets/` y `README.md`.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección aparecerá en la misma sección de Pages.

## Notas

- `index.html` es la página principal del sitio.
- La carpeta `assets/` contiene imágenes y archivos de modelos 3D utilizados por la página.
- Conserva la estructura de carpetas y los nombres de los archivos para que las imágenes y los modelos se carguen correctamente.
